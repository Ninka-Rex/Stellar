# Security Policy

## Reporting a Vulnerability

Email security issues and steps to reproduce to **admin (at) stellardownloadmanager . org**.

Please do not open public issues for severe security vulnerabilities.

## Threat Model

A malicious remote source causing Stellar to write to disk outside the intended location or execute code is a vulnerability. An attacker with local acces manipulating Stellar's files is not a threat - they already control the machine.
